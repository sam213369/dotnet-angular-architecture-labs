# .NET & Angular Architecture Labs

A curated collection of full-stack reference implementations, architectural proofs of concept (POCs), and database optimization labs built with **.NET**, **Angular**, and **SQL Server**.

## Purpose
This repository serves as an engineering workbench for exploring enterprise design patterns, clean architecture, API performance, and modern front-end state management. Each subfolder under `src/` is a self-contained project demonstrating practical solutions to real-world software engineering challenges.

## Core Tech Stack
* **Backend:** .NET / C#, ASP.NET Core Web API, Entity Framework Core, Dapper
* **Frontend:** Angular, TypeScript, RxJS
* **Database:** SQL Server, T-SQL Query Optimization, Indexing Strategies
* **Architecture & DevOps:** Clean Architecture, Repository & CQRS Patterns, Docker, RESTful APIs
